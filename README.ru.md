# Andi Proxy

**Ваша точка доступа. Ваши правила.**

Раздайте один прокси Hysteria2 или SOCKS5 на все устройства в точке доступа Android — root не нужен.

Andi Proxy превращает обычный телефон Android в небольшой автономный прокси-шлюз. Подключите вышестоящий прокси Hysteria2 либо SOCKS5 с аутентификацией, а затем либо направьте сам телефон через локальный VPN, либо раздайте прокси ноутбукам, планшетам и другим телефонам через точку доступа телефона или уже существующую локальную сеть Wi-Fi.

Здесь нет root, нет `iptables`, нет постоянного удалённого управления и нет скрытого облака. Клиенты точки доступа указывают в настройках прокси Wi-Fi адрес `phone-address:2080`; приложения на самом телефоне могут использовать тот же движок правил через локальный VPN с исключениями для отдельных приложений.

> **Клиенты точки доступа должны настроить прокси.** VPN телефона охватывает приложения самого телефона, но не трафик других устройств. Это осознанное решение, работающее без root: обычное приложение не может прозрачно перехватить путь пересылки ядра в точке доступа. Клиенты с поддержкой SOCKS5 могут использовать тот же адрес и порт.

## Зачем Andi Proxy

- **Один вышестоящий прокси — два способа поделиться.** Используйте прокси на этом телефоне, раздайте его другим устройствам или делайте и то и другое сразу. Остановка раздачи не выключает VPN телефона.
- **Настоящая маршрутизация по правилам.** Импортируйте списки правил и файлы конфигурации Shadowrocket или задайте правила для доменов, CIDR и маршрута по умолчанию вручную. `DIRECT`, `PROXY` и `REJECT` — всё работает.
- **Аутентификация там, где она нужна.** Пароли Hysteria2, имя пользователя и пароль SOCKS5, необязательная аутентификация локального прокси, TLS SNI и обфускация Salamander.
- **Учётные данные остаются на телефоне.** Профили шифруются ключом Android Keystore и исключены из резервного копирования. Ни аналитики, ни рекламы, ни телеметрии.
- **Создан для обычных телефонов.** Без root, без модулей ядра, без отдельного VPN-приложения. Проверено на серийном телефоне Android 16 с arm64.
- **Пять языков интерфейса.** Английский, упрощённый китайский, японский, корейский и русский — переключаются в приложении или через системные настройки языка для приложения на Android.
- **Открытый код, воспроизводимые сборки.** GitHub Actions собирает и подписывает отдельный APK для каждого ABI и публикует их с контрольными суммами SHA-256 при каждом теге.

## Установка

Скачайте APK, подходящий вашему устройству, из [последнего релиза](https://github.com/kongdayan/andi-proxy/releases/latest):

| Устройство | APK |
| --- | --- |
| Большинство современных телефонов (64-битный ARM) | [AndiProxy-arm64-v8a.apk](https://github.com/kongdayan/andi-proxy/releases/latest/download/AndiProxy-arm64-v8a.apk) |
| Более старые 32-битные телефоны ARM | [AndiProxy-armeabi-v7a.apk](https://github.com/kongdayan/andi-proxy/releases/latest/download/AndiProxy-armeabi-v7a.apk) |
| Эмуляторы и планшеты x86_64 | [AndiProxy-x86_64.apk](https://github.com/kongdayan/andi-proxy/releases/latest/download/AndiProxy-x86_64.apk) |
| Устаревшие эмуляторы x86 | [AndiProxy-x86.apk](https://github.com/kongdayan/andi-proxy/releases/latest/download/AndiProxy-x86.apk) |
| Не уверены? Один файл на всё | [AndiProxy-universal.apk](https://github.com/kongdayan/andi-proxy/releases/latest/download/AndiProxy-universal.apk) |

Требуется **Android 8.0 (API 26)** или новее. Универсальный APK заметно больше, поэтому лучше выбрать файл для конкретного ABI. Каждый релиз содержит `SHA256SUMS` и заметку `SIGNING.txt` о том, как были подписаны APK.

Android может предупредить, что приложение установлено не из магазина. Для открытого APK, установленного вручную, это ожидаемо. Проект не публикуется в Google Play.

## Быстрый старт

1. **Добавьте сервер.** Откройте **Серверы**, импортируйте профиль HY2/SOCKS5 в формате JSON или введите адрес, порт и учётные данные. Сохраните.
2. **Включите прокси на телефоне.** На главном экране нажмите **Включить прокси телефона** и разрешите запрос VPN. Откройте **Приложения в обход VPN**, чтобы найти и отметить приложения, которые должны подключаться напрямую.
3. **Поделитесь с другими устройствами.** Нажмите **Включить раздачу Wi-Fi** → **Подключите другие устройства**. Подключитесь к показанной сети Wi-Fi и задайте в настройках прокси Wi-Fi клиента значение **Вручную**, указав показанный адрес сервера и порт `2080`. Клиенты с поддержкой SOCKS5 используют тот же адрес и порт.
4. **Настройте маршрутизацию.** Откройте **Правила**, чтобы вставить подписку Shadowrocket, сразу её обновить или задать правила для доменов и CIDR вручную. Правила, серверы и исключения применяются к работающему прокси автоматически.

Если клиент сообщает, что в сети Wi-Fi нет доступа в интернет, выберите **Сохранить подключение**. Точка доступа обеспечивает локальную связь, а доступ в интернет идёт через прокси.

## Как это работает

```text
            ┌──────────────────────────── Android phone ────────────────────────────┐
            │                                                                       │
  Wi-Fi/LAN │  other devices ── HTTP CONNECT / SOCKS5 :2080 ──┐                    │
            │                                                  │                   │
            │  phone apps ── VpnService ── hev-socks5-tunnel ──┤                   │
            │                    (per-app exclusions)          ▼                   │
            │                                            sing-box 1.14.2            │
            │                                         rules / DNS / routing         │
            └──────────────────────────────────────────────────┬───────────────────┘
                                                               │
                                              Hysteria2 or authenticated SOCKS5
                                                               ▼
                                                          upstream
```

- Служба переднего плана запускает закреплённое ядро sing-box со сгенерированной конфигурацией. Конфигурация лежит в приватном каталоге приложения с правами `0600` и удаляется при остановке сеанса.
- Локальный inbound типа `mixed` слушает `2080` и принимает HTTP CONNECT и SOCKS5. Раздача работает явно: клиенты должны сами указать прокси.
- VPN телефона через `hev-socks5-tunnel` передаёт пакеты TUN в SOCKS-слушатель на `2081`, доступный только через loopback, поэтому телефон и клиенты точки доступа используют один и тот же движок маршрутов.
- Android разрешает только один активный VPN. Andi исключает себя из собственного VPN, чтобы избежать петли маршрутизации.
- Бинарник ядра упакован как `libsingbox.so`, поэтому Android распаковывает его в каталог нативных библиотек приложения; приложение не исполняет код, загруженный в записываемый каталог.

Карта компонентов и потоки данных — в разделе [Архитектура](docs/ARCHITECTURE.md).

## Правила и DNS

Приоритет маршрутизации:

1. Проксируемые домены из ручных правил
2. Прямые домены из ручных правил
3. Прямые CIDR из ручных правил
4. Прямое подключение для частных сетей
5. Правила из подписки в исходном порядке
6. Маршрут по умолчанию

`FINAL` из подписки переопределяет ручной маршрут по умолчанию. Без `FINAL` ручной маршрут по умолчанию сохраняется. IP-правила разрешают адрес явно, когда это необходимо; правила `no-resolve` не вызывают дополнительный запрос.

Ручные правила и правила из подписки для доменов также выбирают резолвер: проксируемые домены используют удалённый DoH Cloudflare, прямые — `223.5.5.5`, а имена серверов разрешаются через прямой DNS, чтобы избежать петли. Правила по странам используют разрешённый IP назначения. DNS-запросы клиентов, идущие мимо прокси, при раздаче через точку доступа не перехватываются; VPN телефона перехватывает DNS внутри туннеля и отправляет его в то же ядро.

Импортируются только секции `[Rule]`. MITM, настройка сертификатов, переписывание URL и общие системные настройки игнорируются. Неподдерживаемые записи маршрутизации приводят к ошибке обновления, предыдущий кэш сохраняется, и такие записи никогда не отбрасываются молча.

## Конфиденциальность и безопасность

- Учётные данные серверов и профиль шифруются ключом AES-GCM из Android Keystore. Резервное копирование Android и перенос на другое устройство для этого приложения отключены.
- Рабочая конфигурация ядра записывается с правами `0600` и удаляется при остановке. Конфигурации для проверки подписок временные.
- Подписки должны использовать HTTPS без встроенных учётных данных и фрагментов. Размер загрузки ограничен, перенаправления проверяются.
- Ни аналитики, ни рекламы, ни телеметрии, ни службы удалённого управления. Приложение не выгружает ваш профиль и данные об использовании.
- Бинарник и нативные библиотеки — это закреплённые официальные релизы вышестоящих проектов, проверяемые по SHA-256 в [`scripts/fetch-core.py`](scripts/fetch-core.py).

См. также [Конфиденциальность](docs/PRIVACY.md) и [Уведомления о сторонних компонентах](THIRD_PARTY_NOTICES.md).

## Совместимость и ограничения

- **Проверенная платформа:** серийный телефон Android 16.0, arm64-v8a, страницы памяти по 4 КиБ, без root. Другие ABI и устройства с 16-КиБ страницами памяти собираются, но пока не проверены на реальных устройствах; отчёты приветствуются.
- **Клиенты точки доступа:** приложение создаёт `LocalOnlyHotspot`; на Android 16.0 имя и пароль генерирует Android. Чтобы использовать фиксированные имя и пароль, настройте системную точку доступа и раздавайте её интерфейс. API Android 16.1 для имени точки доступа, задаваемого приложением, скомпилированы, но на устройствах не проверены.
- **Без прозрачного перехвата:** клиенты точки доступа должны указать прокси HTTP/SOCKS5. Игры, приложения только с UDP и проксирование всего устройства требуют клиентского инструмента SOCKS5/VPN/TUN.
- **Один VPN за раз:** Android не разрешает два активных VPN. Andi не может работать одновременно с другим VPN-сервисом.
- **Подписки предоставляет пользователь:** за содержимое правил и их лицензирование отвечает подписчик. Используются только правила маршрутизации.
- **Нет в Play Store:** устанавливайте APK вручную и проверяйте контрольную сумму, если скачиваете с зеркала.

Исторические подробности проверки и оставшиеся особые случаи — в разделе [Проверка](docs/VERIFICATION.md).

## Языки

Интерфейс приложения доступен на языках:

Исправления переводов приветствуются.

## Сборка из исходников

Требования: JDK 17, Android SDK Platform 36, Build Tools 35.0.0, Python 3.10+.

```sh
git clone https://github.com/kongdayan/andi-proxy.git
cd andi-proxy

# Скачиваем закреплённые бинарники sing-box и hev-socks5-tunnel (все ABI + ядро для хоста macOS)
python3 scripts/fetch-core.py

# Указываем Gradle путь к вашему SDK, если ANDROID_HOME ещё не задан
export ANDROID_HOME=/path/to/android-sdk

./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Отладочные APK записываются для каждого ABI в `app/build/outputs/apk/debug/`. Релизные сборки используют то же разделение по ABI; подпись, версионирование и детали выпуска описаны в разделе [Сборка](docs/BUILDING.md).

Полезные проверки:

```sh
python3 scripts/check-i18n.py       # ключи переводов, плейсхолдеры и покрытие
python3 scripts/core_smoke.py       # реальный smoke-тест маршрутизации sing-box на фикстурах (ядро для хоста macOS arm64)
```

Andi Proxy — родственный проект [the companion project](https://github.com/kongdayan/andi-proxy), нативного компаньона для здоровья на macOS, который синхронизирует данные часов Garmin напрямую с Mac. Оба проекта пронизывает одна идея: данные остаются на ваших собственных устройствах, а повседневные инструменты должны быть маленькими, спокойными и надёжными.

Ссылки на автора и проект также есть в приложении в разделе **Настройки → Автор и открытый код**.
