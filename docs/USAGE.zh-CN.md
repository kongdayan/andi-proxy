# Andi Proxy 使用指南

Andi Proxy 有两件互相独立的事：

1. 通过本机 VPN 代理**这台手机**。
2. 通过手机热点或已有 Wi-Fi／局域网，把代理**分享给其他设备**。

两者可以同时开启；停止其中一个不会停止另一个。

## 1. 添加服务器

打开「服务器」，可以：

- 点击「导入配置」，粘贴 HY2／SOCKS5 的 JSON 配置；或
- 选择「SOCKS5」或「HY2 / Hysteria2」，填写地址、端口和认证信息。

SOCKS5 必须填写用户名和密码。HY2 需要认证密码，可选填写 TLS SNI 和 Salamander 混淆密码。默认校验证书；只有了解风险时才跳过。

点击「保存服务器」。

## 2. 代理这台手机

在首页点击「开启本机代理」，允许 Android 的 VPN 请求。

- 手机应用按「规则」分流。
- 「不代理的应用」可以搜索并勾选已安装应用（包含系统应用）。选中的应用绕过 VPN 直连；Andi 自身始终排除，避免路由循环。
- 本机 VPN 与热点共享使用同一个分流核心，不需要先开启热点。

只停止手机代理时，点击「停止本机代理」。正在运行的热点共享会保留。

## 3. 分享给其他设备

1. 在首页点击「开启 Wi-Fi 共享」。系统可能请求「附近设备」或位置权限。
2. 点击「连接其他设备」。引导页会显示热点名称、密码、代理地址和端口 `2080`。
3. 在客户端（电脑、平板或另一部手机）连接显示的 Wi-Fi，打开 Wi-Fi 详情，把代理设为「手动」：
   - 服务器：App 中显示的地址
   - 端口：`2080`
4. 打开网页。如果客户端提示「无互联网」，选择保持连接。

支持 SOCKS5 的客户端可以使用同一地址和端口。App 在同一端口上同时接受 HTTP CONNECT 和 SOCKS5。

共享是显式代理：客户端必须自己设置代理。普通 Android App 在没有 root 的情况下无法透明接管热点的内核转发路径。游戏、纯 UDP 应用和整机代理需要客户端使用 SOCKS5／VPN／TUN 工具。

### 使用已有 Wi-Fi

如果手机和客户端已经在同一个 Wi-Fi，在首页展开「使用系统热点或已有 Wi-Fi」，选择手机的局域网地址，点击「共享此网络」。不想创建热点时可以用这种方式。

### 使用系统热点

Android 16.0 由系统生成 App 创建的 LocalOnlyHotspot 名称和密码。如果需要固定名称或密码：

1. 打开「设置 → 系统热点设置」，在 Android 中修改名称、密码和频段。
2. 回到 Andi 首页，展开「使用系统热点或已有 Wi-Fi」，选择热点接口，点击「共享此网络」。

系统热点和 App 热点是两个不同的网络。修改系统热点不会改变 App 热点。Android 16.1 起提供 App 自定义热点名称和密码的接口；代码已包含该分支，但尚未在 16.1 实机验证。

## 4. 规则与订阅

打开「规则」。

- **规则订阅**：粘贴 Shadowrocket `.conf` 或规则列表的 HTTPS 地址。点击「立即更新」马上更新；更新失败会保留上一次缓存。
- **启动时自动更新过期规则**：启动代理时，如果缓存超过 24 小时则更新。
- **手动分流**：选择默认出口（走代理或直连），然后按行填写走代理的域名、直连域名和直连网段。
- **保存规则**：运行中的代理会自动应用新规则。

订阅只使用 `[Rule]` 部分；MITM、证书设置、网页重写和 General 系统设置会被忽略。不支持的路由规则会让更新失败，而不是静默丢弃。

优先级：手动代理域名 → 手动直连域名 → 手动直连 CIDR → 私网直连 → 订阅原顺序 → 最终出口。订阅中的 `FINAL` 会覆盖手动默认出口。

## 5. 外观、语言与快捷操作

- **外观**：跟随系统、浅色或深色主题，点击「应用主题」。
- **语言**：跟随系统、English、简体中文、日本語、한국어、Русский。Android 13 及以上也可以在系统的应用语言设置中修改。
- **快捷操作**：添加可调整大小的桌面小组件，或添加下拉快捷设置磁贴。长按小组件并拖动边框可调整大小。
- **高级设置**：可选的共享代理认证、设备诊断、作者与开源信息。

## 6. 常见问题

| 现象 | 检查 |
| --- | --- |
| 客户端提示「无互联网」 | 选择保持连接；热点本身不提供直连互联网。确认客户端代理地址是手机地址、端口 `2080`。 |
| 客户端连不上代理 | 确认共享已开启、客户端在同一个热点／局域网，手机防火墙或「私人 DNS」没有拦截。 |
| 本机 VPN 无法启动 | Android 同时只允许一个 VPN。停止其他 VPN 应用，并允许 Andi 的 VPN 请求。 |
| 订阅更新失败 | 代理未运行时，订阅地址必须能在不走代理的情况下访问，并且必须是 HTTPS。旧缓存会继续使用。 |
| 核心提示「校验失败」 | 检查服务器字段和规则。错误信息会包含核心原因；日志不会显示认证信息。 |
| 无法在 Andi 中修改热点名称／密码 | Android 16.0 由系统生成。请使用系统热点并共享其接口，或等待 Android 16.1 支持。 |
| 小组件不刷新 | 安装后先打开一次 Andi，再重新添加小组件。部分桌面会缓存小组件布局。 |

提交问题时请附上 Android 版本、设备型号、ABI、App 版本、当时是否开启本机 VPN 或共享，以及完整错误文字。不要包含服务器认证信息、带令牌的订阅地址或个人数据。

## 7. 停止与清理

停止代理会删除运行时核心配置并关闭 VPN／TUN。卸载 App 会删除加密配置、订阅缓存和日志；Android Keystore 密钥也会随应用删除。
